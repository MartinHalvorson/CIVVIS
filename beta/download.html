CIVVIS

The browser build is the engine slowed to something a tab can carry. This is the engine itself: one self-contained program, no installer, no account, no network. Games run as fast as your processor will run them, and keep running long after this website is gone.

Every link is the newest release. Older builds and their checksums stay up permanently.

Run it

macOS and Linux need the file marked executable once — chmod +x civvis-macos-aarch64 — and macOS will want it cleared in Privacy & Security the first time, because the build is not signed by an Apple developer account. 

civvis simulate --players 8 --turns 500       one whole game, printed
civvis benchmark                              how many turns a second this machine plays
civvis soak --games 24                        many games, with anomalies flagged
civvis tournament                             AIs played off against each other
civvis play                                   the viewer, in your own browser
civvis play --spectate                        the same, all seats played by the AI

civvis play opens the same interface as the test build, served from your own machine at http://127.0.0.1:8765, with the engine running natively behind it instead of inside the tab.

What you are getting

  • One file. The rules, the artwork and the interface are all compiled in. Nothing is fetched at runtime and nothing is installed.
  • Offline, permanently. It never contacts a server. A copy kept on a disk will still play in ten years.
  • Deterministic. The same seed replays the same game exactly, which is what makes the simulation useful rather than merely watchable.
  • Free software, GPLv3. The whole engine is public — build your own, change the rules, keep the result. Anything you ship built on it stays free the same way.

Or build it yourself

git clone https://github.com/MartinHalvorson/CIVVIS
cd CIVVIS
cargo build --release
./target/release/civvis benchmark

Rust stable and nothing else; the engine has two dependencies, both of them serde.
