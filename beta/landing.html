CIVVIS.ai

An open source Civilization VI Simulator for AI strategy development

GitHub Dev Progress

CIVVIS is an open source re-implementation of the 4X turn-based strategy game Sid Meier’s Civilization VI — built with a simulator UI wrapping the headless mode game logic. Everything here is a best-effort work in progress; the AI logic in particular still needs a good bit of work. Feel free to clone the code, request new features or report any issues you run into.
