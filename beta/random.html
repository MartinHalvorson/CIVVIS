How it is counted

Against the AI, a game counts once however many runs it took: a win is a CIVVIS victory; a loss is a rival’s victory, our elimination, or a game conceded early. A game’s victory aimed for is the one its seat was set to aim for, off the first of its runs’ summaries that names one; a game whose summaries name none is not in the chart. In self-play every seat is a CIVVIS AI agent and one in six wins, so a seat’s par is 16.7%; a self-play seat does not record the victory it aimed for. A figure over fewer than ten games is faint.
