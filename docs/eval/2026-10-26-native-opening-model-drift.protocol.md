# Fixed passive Native opening-model audit

Use exactly the eighty registered Native opening-census cases and all eighty-
three actual captured reads in the companion selection. The prior census has
already checked every whole state against an original Native event. This audit
adds a current-model reconstruction, not a new game selection or outcome claim.

Freeze the actual 0b669 adapter bytes by SHA-256, not a label. For each read,
reconstruct its actual prefix with captured_input, verify the prior byte count
and SHA, and write only that prefix to a fresh disposable mirror. Never point a
query at the real events or orders channel. Use passive --dump-mirror at the
exact target turn; no AI orders or Native commands are issued. Preserve command,
exit, stdout/stderr and all errors. Do not read later events to improve a match.

Match own cities by Native offset coordinates, retaining missing/extra/duplicate
positions as structural findings. Compare host city.yields with model_yields,
the diagnostic BEFORE per-city host correction. The model already incorporates
some host per-plot corrections; describe that remaining scope explicitly.
Displayed corrected yields are retained separately as calibration only: matching
by construction is not evidence that the underlying model is correct.

Use the existing 0.05 absolute yield tolerance. Keep signed/raw deltas for all six
yields, counts of material differences and unknown coverage. Compare raw model
housing and its source categories with Native housing, and preserve fractional
versus displayed whole-number readings separately. Do not assume every native
housing value is an integer. Retain negative/ambiguous amenities instead of
coercing them to zero; -1 can be an exporter fallback and is reported separately.
No missing accessor becomes agreement or a Native rule defect.

Every actual read remains separate. If map availability or modeled output varies
within one fixed frame, retain all variants and flag the ambiguity; never choose
the best fit. Sparse ten-turn samples do not prove the length of a consecutive
turn episode. No growth forecast or strategic strength claim follows just from
a current city-yield comparison.

Before queries, run semantic controls for coordinate matching, raw-versus-
corrected yield separation, missing/nonfinite readings, fractional housing,
ambiguous accessors and variant preservation. Record the exact diagnostic source
and binary identity. Seal all responses, comparisons, controls and failures with
per-file read times and hashes. No live trial, baseline, game setting, source
policy, rules data or ledger changes belong to this audit. Any concrete mismatch
needs its own primary-source explanation and regression before a gameplay fix.
