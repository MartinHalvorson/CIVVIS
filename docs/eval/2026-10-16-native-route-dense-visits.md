# Query-local dense visits for land siege routes

The candidate used **1.70% less child CPU** by median paired comparison (1.72% pooled) on this fixed Native ARM64 artifact-profile trace. All six registered CPU criteria and the separate compatibility requirements passed; the query-local dense visit optimization is retained.

The fixed study was registered before any new control build, experimental edit, compatibility game or timing arm. One read-only call graph requested for eight seconds of the previously retained Native artifact-profile pipeline identified the predicate route helper as a candidate for inspection. Sampling counts select a hypothesis; they are not an A/B speedup estimate. The diagnostic was not repeated to chase peaks.

The experiment replaces only the predicate router's per-query ordered visited set with dense flags indexed by `TileGrid::index_of`, retaining an ordered-set fallback for an unindexable position. Membership is marked at exactly the old point. The initial/blocked-target guards, territory and occupancy checks, ZOC lock, query-memo scope, blocked-predicate call order, neighbor/FIFO order and selected first step are preserved. The original set-based router remains byte-for-byte unchanged as an independent oracle. No Game/AI cache, policy, gene, game rule or strategy changes.

The baseline Native artifact already existed before this registration: official workflow `38897295560`, source `e593eb9cbeb20d2b4384e31a512f367b4bc2a13f`. Its complete source manifest, compiler/profile, ARM64 headers, 235 selected test executions, both executable checksums and local simulator/orders smokes were verified in the earlier study. This study reuses those immutable executables and their exact source checkout, with provenance and checksums reverified. No earlier timing observations are reused. Starting-main production inputs are byte-exact to this source; three new test-only controls are built against unchanged production before the experimental edit, alongside the five existing controls. Registration is not represented as preceding that historical baseline build.

Eight focused controls passed before and after the edit: three new dense-membership/frozen-predicate controls and five existing set-router/caller controls. The new controls compare exact first steps, blocked-predicate probe order, sparse grids, unindexable starts, initial/target/ZOC gates and ordinary-cache behavior, with positive reachability guards. Candidate siege and route suites passed, followed by 6,147 passes in the full locked serial suite, all-target developer-tools checking and changed-Rust quality. The test-only baseline source is `fc34adeeb4827d1fcd8c01a48ad711c3a8a364f7`; all 759 preexisting production inputs match the reused artifact after removing only the appended cfg(test) module, and the only additional file is its test child.
