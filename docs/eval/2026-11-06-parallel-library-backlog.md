# Parallel first Library and backlog Builder — offline activation evidence

`parallel-library-backlog` is an independent default-off scheduling experiment for an assigned Science seat's opening. It coordinates two existing claims without changing their jobs, eligibility, Builder quota or build budgets. It introduces no valuation credit or Civilization VI rule.

This is one-world mechanism evidence, not independent samples or recovered turns.

Later queue writers, policy changes and host execution can invalidate the forecast.

The opt-in reuses the original claims' selectors. All four native quotes must be finite and positive. The swap must improve both-jobs-ready time, make the Library earlier and not increase the sum of quoted completion times. Absent quotes or a failed condition leave the old ordering intact.

The later Campus-building claim is skipped only while the early Library remains at its head, retaining one final Campus-building claim; if another intervening writer replaces it, the ordinary claim can still run.
