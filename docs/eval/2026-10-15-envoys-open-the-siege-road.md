The current verified c164 native controller still splits the two envoys on the exact captured turn-168 request. A fresh one-shot process does not reproduce the historical declaration because it lacks the previous road-hold memory. These proposal and execution observations are kept separate.

The default-off `envoys-open-the-siege-road` treatment gives an affordable suzerainty package priority over the ordinary one-envoy economic ranking when a current or previous-turn Stage hold names that city-state as blocking a siege against an existing major enemy. The unit must still belong to us, the target must still be an enemy major's city, the route must still name that blocker, and sending influence must be currently legal. Existing passage, war with the minor, a stale hold or a dead unit disqualifies it. Merely tying a rival's delegation does not buy passage.

Physical placement cost comes from the shared envoy investment model, including Diplomatic League, Containment and Amani. The cheapest complete package wins first; the remaining cost is recomputed after each placement. The Native caller supplies its existing eight-order batch limit before planning, and the baseline ancillary fallback preserves the unissued balance. The headless adapter remains unbounded.
