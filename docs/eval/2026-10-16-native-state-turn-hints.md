# Cache lexical turn hints for the Native reader

The candidate used **3.76% less child CPU** by the median paired comparison (3.74% pooled) on this fixed CI trace. Every registered acceptance criterion passed; the lexical turn-hint cache is retained.

The retained Native reader repeatedly inspects old large state records to decide which turn they could describe. The candidate keeps only the byte offsets of lexically valid integer `turn` members for each state-line range in the existing per-thread retained-log cache. Old lines can then be rejected without scanning their full text again. Accepted and ambiguous candidates still pass through the unchanged old classifier, typed header and full JSON parser. Nesting, duplicates, escaped/invalid fields, numeric spelling, ordering, and parser ownership retain their existing behavior; this does not reinterpret the header or cache a Game/AI state.

The metadata follows the existing log-cache lifecycle. Proven append-only growth keeps offsets into its unchanged prefix; an existing full-read/path reset discards them. A retained older or arbitrary raw buffer uses the original uncached path. The existing file/tail validation rules are unchanged. Controls compare with the old classifier across ambiguous/nested/duplicate/numeric headers, growth, rewrites, file switches, old buffers, lookback, state/snapshot agreement and confirmed-death ordering.

The fixed study was registered before the baseline compilation and experimental edit. It has eight A/A and sixteen A/B pairs in two balanced reversed interleaves: 48 fresh persistent children and 1,968 requests. Every child receives the same 41 original increasing turn-opening prefixes, turns 160–200, from one historical **Emperor** world, `civvis-20261015T120650Z`. Both arms use `--serve --fresh-board --explain` and the same 283 flags: the unchanged global 282 plus `envoys-open-the-siege-road`. No global flag is enabled by this change.

The metric is per-child user plus system CPU. Startup and child capture I/O remain included; parent input append and auditing are excluded. Normal background services continue. During the fixed block, the root only read status, sent commentary and waited; it did no checkout, cohort preparation, source editing, compilation, profiling or other owned heavy work. The 21 ambient samples observed no rustc or active owned Native cohort. Native work has priority at pair boundaries. No run is replaced, filtered, or added after outcomes; all 48 are retained. Every full parsed response must match except only top-level `input_capture` metadata, and each actual capture/index must reconstruct every registered original prefix. Acceptance also requires negative median and pooled A/B deltas, with the absolute A/B median exceeding the absolute A/A median and both A/A and A/B interquartile ranges.

All 48 registered arms completed. All 1,968 full parsed responses are identical. A/A median -0.100105%, pooled -0.230632%, IQR 0.349906 percentage points. A/B median -3.764376%, pooled -3.744297%, IQR 0.483776 points. All six registered acceptance criteria passed.

Four added reader controls and 446 mirror tests passed (two existing ignores). The full serial suite passed 6,135 tests, with 51 existing library ignores and four doc ignores. All-target developer-tools checking and changed-Rust quality checks passed. The baseline initially failed to compile because one new test expected floating-point Gold instead of the exported i64; no test ran or binary was built on that failed source. Its source/patch/log are retained. The fixture was corrected before the valid baseline controls/build and before the experimental edit. The valid baseline source is `1e6b8d2c7bb7ff53b6c22599a54c41228abbe120`; its immutable decider was archived first. All candidate checks and fixed timing use `aa7616562e72c22f16ad987e0f81135b2142e849`. Main integration preserves every tracked runtime-input byte from the measured source; completed semantic tests are carried without replay for identical runtime source. The unchanged classifiers and full JSON parser are independently byte-compared with baseline, including the still-present JSON clone from the withdrawn prior study. No Native game or host UI action was performed.

This establishes only a captured-protocol CI child-CPU result on this ARM64 Mac. It establishes no fresh Native execution, Deity victory, release-binary improvement, overall game-speed improvement or strength gain. It does not combine or multiply previous performance percentages. Source/binary hashes, commands, all raw responses and metrics, capture indexes, full source patches, all validation results including the initial test-compile failure, and ambient observations are retained. The previously committed original input is independently hash-checked and reused without duplication.
