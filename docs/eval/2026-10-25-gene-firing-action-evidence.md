# Recorded action comparisons as firing evidence

An independent treatment draw can produce nonzero outcome statistics even
when a candidate changes no action. The existing gate retains its historical
statistical acceptance, while this change adds a direct route for captured
Native-adapter proposal comparisons. It changes no controller, gene default,
waiver, ledger source or outcome rating.

The new artifact names a repository-local, SHA-256-bound archive and raw result
members. The reader never extracts files. It checks complete successful
queries, a shared captured-input digest, observed treatment and forced sets
differing only by the named gene, otherwise identical genomes and arguments,
and at least one different proposed order. Explanation text and declared
changed counters are insufficient. This reads recorded query evidence; it
does not independently rerun the controller or attest host execution, a
whole-game effect, or a win.

The regression suite with the old implementation has 11 intended failures.
The candidate passes all 24 firing-gate tests, including changed/unchanged
orders, journal-only differences, failed queries, extra genome changes,
changed arguments/binaries, corrupt/path-escaping archives and missing
members. The same 24 pass under optimized Python, so checks do not depend on
assertions. Seven existing CI-wiring tests also pass. The real `--max 0`
ratchet runs inside the suite. A local check against the separately archived
Istanbul captured-input comparison accepts its single changed proposal;
that candidate remains a separate PR and receives no strength inference.

The 8-member evidence archive contains raw failed/passing logs, frozen tool
and test sources and a verified member manifest: 16,704 bytes, SHA-256
`ed5c60f10328e6522004aaa07b17b1c10bd5d4deaa150d46cd956f71aa082d45`.
Full Rust execution and gameplay soak are not applicable to this Python-only
artifact reader and documentation change; focused tests exercise the actual
CI gate. GitHub integration checks remain pending.
