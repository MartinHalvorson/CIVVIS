# Native state-value move: fixed study and withdrawal

The experimental value move is withdrawn. The absolute median A/B delta did not exceed the A/B interquartile range. The fixed block is closed; the runtime change is withdrawn without another run or extension. All fixed runs, responses, source patches, and failed criteria are retained; no performance gain is claimed.

The Native parser already owns a complete JSON value. It previously cloned that value for typed deserialization, then borrowed the original to list schema gaps. The candidate computes the same pure gap list first and consumes the owned value with the same deserializer. It changes no field, parser, default, warning list, error result, game rule, AI policy, cache, gene, Native pin, or forcing setting. Valid nested exports, sparse/duplicate-key inputs, and invalid JSON/typed errors are compared against the original clone pipeline.

The fixed study was registered before the baseline build and experimental edit. It has eight A/A and sixteen A/B pairs, in two balanced reversed interleaves: 48 fresh persistent children and 1,968 requests. Each child receives exactly the same 41 original increasing turn-opening prefixes, turns 160–200, from one historical **Emperor** world, `civvis-20261015T120650Z`. Both arms use `--serve --fresh-board --explain` and the same 283 flags: the unchanged global 282 plus `envoys-open-the-siege-road`. No global flag is enabled by this work.

The metric is per-child user plus system CPU. Startup and child capture I/O remain included; parent input append and auditing are excluded. Normal services continue, and ambient observations are retained. During this block the root process also created a private read-only source checkout, prepared future-cohort metadata/scripts, and dispatched a remote ARM64 build (plan registration 07:32:22 UTC; dispatch 07:32:52 UTC). This incidental local file work could add cache or scheduling noise. It is disclosed without filtering, replacement, or a rescue run; the registered criterion fails and the runtime is withdrawn. Native work has priority between pairs. No run is replaced, filtered, or added after outcomes; all 48 are retained. Every complete parsed response must match except only the top-level `input_capture` metadata. Actual archived inputs and indexes must reconstruct every registered prefix. Acceptance also requires negative median and pooled A/B deltas, with the absolute A/B median exceeding the absolute A/A median and both A/A and A/B interquartile ranges.

All 48 registered arms completed. All 1,968 full parsed responses are identical. A/A median +0.135993%, pooled +0.025468%, IQR 0.433506 percentage points. A/B median -0.470036%, pooled -0.446384%, IQR 0.554816 points. Failed criteria: exceeds_ab_iqr.

Three added parsing-equivalence controls and 445 mirror tests passed (two existing ignores). The full serial suite passed 6,134 tests. All-target developer-tools checking and changed-Rust quality checks passed. The unchanged baseline controls passed and its immutable decider was archived before the experimental edit. All candidate checks and fixed timing use the same source `112d6e217ce894854cbcb26e1d18508579eb1379`. The runtime change and its added test support are then withdrawn. The final documentation source is byte-for-byte current main across all tracked runtime inputs; no new local Rust test is repeated for documentation-only changes. The protected GitHub workflow still validates the final PR. No new Native game or host action was performed.

This is one captured-protocol CI measurement on this ARM64 Mac. It establishes no fresh Native execution, Deity victory, release-binary improvement, overall game-speed improvement, or strength gain. It does not combine or multiply previous performance percentages. Source/binary hashes, commands, all raw responses and metrics, captured-input indexes, full source patches, validation results, and ambient observations are retained. The previously committed original input is reused and independently hash-checked rather than duplicated.
