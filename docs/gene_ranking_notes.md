⚠ **The rule this pair is really about.** `holy-lane-parity` left the code in #2266 on a -27 null, was priced at +63 by a screen already running, was restored in #2299 and confirmed at +99 (z +4.05) in #2307. A cull is irreversible in a way a default is not -- a gene left `off` costs one row in a foldover screen and no games, while a gene removed can never be re-priced -- so the bar for removing code is a reading on the instrument the agent is actually being screened on, not the best reading available.
