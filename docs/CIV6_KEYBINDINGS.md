# CIVVIS keyboard shortcuts

CIVVIS intentionally keeps a small, fixed keyboard map. These are the only
global action shortcuts.

| Key | Action |
| --- | --- |
| 1 | Next action |
| 2 | Toggle the Settler map |
| 3 | Toggle map-tack placement |
| F | Fortify the selected unit |
| A | Alert the selected unit |
| Right Arrow | Next city in placement order; with no city selected, start at the capital |
| Left Arrow | Previous city in placement order; with no city selected, start at the last placed city |

City placement order is ascending city ID, which is allocated as each city is
placed. Buttons, pointer controls, and standard Escape dismissal remain
available outside this action map.
